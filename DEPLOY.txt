GITHUB PAGES UPDATE

1. Extract Wonguk_Lee_GitHub_Pages.zip on your computer.
2. Open your existing GitHub Pages repository.
3. Choose Add file > Upload files.
4. Upload the extracted contents, including index.html, style.css, site.js,
   assets, and materials. Do not upload the ZIP itself or an enclosing folder.
5. Commit the changes to your published branch.
6. Wait for the GitHub Pages deployment to finish, then reload the website.

Keep your existing Pages configuration: publish the repository root from main.
The package does not require npm, a build workflow, or a GitHub integration.
