GitHub Pages 업데이트

1. ZIP 압축을 풉니다.
2. 기존 lwg52534-dev.github.io 저장소에서 Add file → Upload files를 선택합니다.
3. 압축을 푼 폴더 자체가 아니라, 그 안의 index.html, style.css, site.js, assets 폴더, materials 폴더를 올립니다. 같은 경로의 기존 파일을 교체합니다.
4. Commit changes로 저장합니다. 기존 GitHub Pages 설정은 그대로 사용하면 됩니다.
5. Actions에서 배포가 완료되면 사이트를 새로고침합니다. 예전 내용이 보이면 강력 새로고침하거나 시크릿 창에서 확인합니다.

중요: index.html이 assets 또는 materials 안에 들어가지 않고 저장소 최상위에 있어야 합니다. assets와 materials만 올리면 본문과 디자인은 업데이트되지 않습니다.
