# Wonguk Lee — V11 readable typography

The complete website is in index.html. It contains the new Wonguk Lee. wordmark, Space Grotesk / DM Sans / IBM Plex Mono fonts, supporting text of at least 14px, tighter paragraph leading, original research images, interactive search, and PDF documents.

## Update GitHub Pages
1. Open the repository root.
2. Upload index.html from this archive, replacing the existing index.html.
3. Commit the change. Keep the existing GitHub Pages configuration.
4. After the deployment completes, refresh the site. If necessary use Ctrl+Shift+R.

The page does not load any older portfolio CSS or JavaScript files. The same index.html can be opened locally for an independent preview. All original document PDFs and figure assets are also retained in this archive for separate use; the website works from index.html alone. Font licenses are embedded in the HTML and retained with the font files.

Appearance: edit the embedded <style> in index.html. Content: edit the HTML. Interactions: edit the script at the end. No build is required.
